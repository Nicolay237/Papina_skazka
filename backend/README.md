# Папина сказка — бэкенд

FastAPI. Все фразы лежат в `app/data/*.txt` и читаются в память при старте.

## Как устроена база

Два измерения:

- **Часть сказки (слот)** — роль фразы: герой, спутник, место, время, занятие,
  препятствие, помощник, слова людей, концовка, мораль. Описаны в `app/catalog.py`.
  У каждой части свой файл (`kto`, `s_kem`, `gde`, `kogda`, `chto_delali`,
  `prepyatstvie`, `lyudi_skazali`, `delo_konchilos`, `moral`); помощник берёт
  фразы из того же файла, что и герой (`kto`).
- **Тема** — тег фразы (`fairy`, `cartoon`, `movie`, `space`, `quest`, `home`,
  `school`, `sport`, `spooky`, `nonsense`). Тем может быть несколько, через запятую.

Служебные теги:

- `any` — фраза подходит к любой теме и попадает в любую подборку;
- `adult` — фраза для взрослых (алкоголь, взрослые деньги и сериалы, политики,
  грубоватые словечки, фильмы 18+). В детском режиме такие фразы не выпадают.

### Формат строки

```
темы | фраза
темы | род | фраза        # только kto: m — он, f — она, n — оно, p — они
```

Пустые строки и строки с `#` пропускаются. Пример: `fairy,cartoon | m | Колобок`,
`quest,adult | в бочке с пиратским ромом`.

### Правила для фраз

Фраза хранится в том виде, в каком встаёт в предложение: предлоги и падежи уже
внутри, склонять ничего не нужно.

| Файл | Что писать | Пример |
|---|---|---|
| `kto` | именительный, с заглавной | `Три поросёнка` (род `p`) |
| `s_kem` | творительный с предлогом, со строчной | `со Змеем Горынычем` |
| `gde` | предложная группа, со строчной | `на опушке тёмного леса` |
| `kogda` | обстоятельство времени, со строчной | `пока варилась каша` |
| `chto_delali` | инфинитив, со строчной | `вязать крючком` |
| `prepyatstvie` | предложение в прошедшем времени, без точки | `налетел страшный ураган` |
| `lyudi_skazali` | реплика с заглавной и знаком в конце | `Вот это поворот!` |
| `delo_konchilos` | придаточное в прошедшем времени, без «что» и точки | `козлята забодали серого волка` |
| `moral` | фраза после «Мораль сей сказки такова:», со знаком в конце | `друзья познаются в беде.` |

Текст собирается в `app/story.py` из нескольких вариантов построения, например:

```
{Кто} познакомился / подружился / столкнулся нос к носу {с кем} {где}, {когда}.
Там они принялись / стали / решили {что делать}.
Но вдруг {препятствие}. {Помощник} пришёл на помощь.
Люди говорили: «{реплика}»
Дело кончилось тем, что {концовка}.
Мораль сей сказки такова: {мораль}
```

Глаголы согласуются с героем и помощником по роду и числу. Необязательные части
можно отключить — текст перестроится («Колобок отправился навстречу приключениям»).

### Главы и ссылки

«Продолжить сказку» дописывает главу с теми же героями (до 5 глав). Мораль всегда
в самом конце.

Ссылка на сказку — `/s/<код>`. Код хранит номер случайности (`seed`) и короткие
хеши выбранных фраз, поэтому сервер ничего не запоминает, а сказка по ссылке
восстанавливается слово в слово. Из этого следуют два правила:

- **не меняйте текст фраз, которые уже могли попасть в ссылки** — ссылка с такой
  фразой перестанет открываться (опечатку лучше исправить, ссылкой можно пожертвовать);
- **новые части добавляйте только в конец списка `SLOTS`** в `catalog.py`, порядок
  показа на экране задаёт отдельный список `UI_ORDER`.

Если сайт раздаёт FastAPI (собранный `frontend/dist` рядом), для `/s/<код>` в страницу
подставляется описание с началом сказки — его показывают мессенджеры в превью.

### Добавление фраз

1. Допишите строку в нужный файл.
2. `python scripts/check_bank.py` — ловит дубликаты, смесь латиницы с кириллицей,
   неверный регистр/формат и слова, которых нет в словаре (имена и сленг после
   проверки глазами добавляйте в `scripts/known_words.txt`).
3. `python -m pytest`.

В каждой теме должно быть не меньше 12 фраз на каждую часть даже в детском режиме —
это проверяют тесты.

## API

- `GET /api/meta` — темы, группы, части сказки (в порядке сюжета), вопросы «Чепухи».
- `POST /api/options` `{slot, themes, kid, limit, exclude}` — случайные варианты для ручного выбора.
- `POST /api/story` `{themes, kid, include, answers}` — собрать сказку. `themes: []` — все темы;
  `kid` — детский режим; `include` — какие части включить (по умолчанию все; герой и
  занятие обязательны); `answers` — фразы, выбранные вручную (`{slot: text}`).
- `GET /api/story/{code}` — сказка по коду из ссылки.
- `POST /api/story/continue` `{code, themes, kid, include}` — дописать главу.
- `GET /api/health`

Ответ со сказкой: `code`, `story` (весь текст), `chapters` (абзацы по главам),
`picks` (какие фразы выбраны, с номером главы), `can_continue`.

Swagger — `/docs`.

## Настройки окружения

- `ALLOWED_ORIGINS` — адреса фронтенда для CORS через запятую (по умолчанию dev-сервер
  Vite). Нужен, только если сайт и API на разных адресах.
