# Папина сказка — бэкенд

FastAPI. Все фразы лежат в `app/data/*.txt` и читаются в память при старте.

## Как устроена база

Два измерения:

- **Часть сказки (слот)** — роль фразы: герой, спутник, место, время, занятие,
  слова людей, концовка. Один файл на слот: `kto`, `s_kem`, `gde`, `kogda`,
  `chto_delali`, `lyudi_skazali`, `delo_konchilos`.
- **Тема** — тег фразы (`fairy`, `cartoon`, `movie`, `space`, `quest`, `home`,
  `school`, `sport`, `spooky`, `nonsense`). У фразы может быть несколько тем
  через запятую. Тег `any` — универсальная фраза, попадает в любую подборку.

Темы и слоты описаны в `app/catalog.py`.

### Формат строки

```
темы | фраза
темы | род | фраза        # только kto: m — он, f — она, n — оно, p — они
```

Пустые строки и строки с `#` пропускаются. Пример: `fairy,cartoon | m | Колобок`.

### Правила для фраз

Фраза хранится в том виде, в каком встаёт в середину предложения: предлоги и
падежи уже внутри, склонять ничего не нужно.

| Слот | Что писать | Пример |
|---|---|---|
| `kto` | именительный, с заглавной | `Три поросёнка` (род `p`) |
| `s_kem` | творительный с предлогом, со строчной | `со Змеем Горынычем` |
| `gde` | предложная группа, со строчной | `на опушке тёмного леса` |
| `kogda` | обстоятельство времени, со строчной | `пока варилась каша` |
| `chto_delali` | инфинитив, со строчной | `вязать крючком` |
| `lyudi_skazali` | реплика с заглавной и знаком в конце | `Вот это поворот!` |
| `delo_konchilos` | придаточное в прошедшем времени, без «что» и точки | `козлята забодали серого волка` |

Текст собирается из четырёх предложений (`app/story.py`):

```
{Кто} познакомился {с кем} {где}, {когда}.
Там они принялись/стали/решили {что делать}.
Люди говорили: «{реплика}»
Дело кончилось тем, что {концовка}.
```

Необязательные части (спутник, место, время, слова людей, концовка) можно
отключить — текст перестроится («Колобок отправился навстречу приключениям»).

### Добавление фраз

1. Допишите строку в нужный файл.
2. `python scripts/check_bank.py` — ловит дубликаты, смесь латиницы с кириллицей,
   неверный регистр/формат и слова, которых нет в словаре (имена и сленг после
   проверки глазами добавляйте в `scripts/known_words.txt`).
3. `python -m pytest`.

В каждой теме должно быть не меньше 12 фраз на каждую часть — это проверяют тесты.

## API

- `GET /api/meta` — темы, группы, части сказки, общее число фраз.
- `POST /api/options` `{slot, themes, limit, exclude}` — случайные варианты для ручного выбора.
- `POST /api/story` `{themes, include, answers}` — собрать сказку. `themes: []` — все темы;
  `include` — какие части включить (по умолчанию все; герой и занятие обязательны);
  `answers` — фразы, выбранные вручную (`{slot: text}`), остальное выпадет случайно.
- `GET /api/health`

Swagger — `/docs`.

## Настройки окружения

- `ALLOWED_ORIGINS` — адреса фронтенда для CORS через запятую (по умолчанию dev-сервер
  Vite). Нужен, только если сайт и API на разных адресах.

## Старые данные

`legacy_banks/` — исходные JSON-банки до переработки (19 из 26 файлов приложение
не использовало). Можно удалить.
