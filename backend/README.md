# Генератор сказок — бэкенд

FastAPI-приложение по мотивам семейной игры «Чепуха». 7 категорий готовых
фраз (Кто / С кем / Где / Когда / Что делали / Люди сказали / Дело
кончилось тем) хранятся в JSON, генератор случайно берёт по одной фразе
из каждой категории и склеивает их в связный (хоть и абсурдный) текст.

Фразы в банках уже полностью готовы — с предлогами и падежами («с
Дикобразом», «у Замка Графа Дракулы»), поэтому никакого морфологического
склонения не требуется: вся работа генератора — выбрать фразы и аккуратно
поправить регистр букв на стыках предложений.

## Структура

```
backend/
  requirements.txt
  app/
    main.py         — FastAPI-приложение и эндпоинты
    schemas.py       — Pydantic-модели запросов/ответов
    questions.py      — список 7 категорий и путь к их банкам
    story.py           — сборка текста из выбранных фраз
    word_banks/*.json  — 7 файлов с фразами (по одному на категорию)
    morphology.py      — модуль склонения слов (pymorphy3), сейчас не
                          используется генератором, оставлен на случай,
                          если понадобится смешивать готовые фразы
                          с отдельными словами, требующими склонения
```

## Запуск

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

Документация Swagger — на http://127.0.0.1:8000/docs

## Эндпоинты

- `GET /api/questions` — список из 7 категорий вместе со всеми фразами.
- `POST /api/generate` — тело запроса `{"answers": {"kto": "Колобок", ...}}`
  (все 7 id обязательны, значения — фразы строго из соответствующего
  банка). В ответ `{"story": "..."}`. При отсутствующем ответе или фразе
  не из банка — код 400 с описанием ошибки.
- `POST /api/generate/random` — без тела запроса, сам случайно выбирает
  фразы. Это основной сценарий: фронтенд просто нажимает кнопку.
- `GET /api/health` — проверка живости сервиса.

## Как устроена сборка текста

`story.py` берёт 7 выбранных фраз и собирает 4 предложения:

```
{Кто} познакомились {с кем} {где}, {когда}.
Там они {что делали}.
Люди говорили: «{люди сказали}»
Дело кончилось тем, что {дело кончилось тем}.
```

Мелкие технические детали:
- фразы для «где»/«когда»/«что делали» приводятся к строчной букве —
  в банке они хранятся с заглавной (как самостоятельный ответ на вопрос),
  но здесь становятся серединой предложения;
- в банке «Дело кончилось тем» часть фраз уже начинается со слова «Что»
  (заготовка под «тем, что...»), а часть — нет; это приводится к единому
  виду перед склейкой;
- если фраза уже заканчивается знаком препинания (одни фразы в «Люди
  сказали» и «Дело кончилось тем» заканчиваются точкой или воскл. знаком,
  другие — нет), лишняя точка в конце предложения не добавляется.

Каждая фраза — законченный речевой оборот: подобранные грамматически
корректно, но не связанные общим родом/числом персонажа комбинации
(«Чебурашка познакомились...») — это нормально и часть духа игры: в
оригинальной «Чепухе» участники отвечают на вопросы, не видя ответов
друг друга, поэтому несостыковки — часть юмора, а не баг.

## Обновление банков фраз

Файлы в `word_banks/` — обычный JSON-массив строк. Чтобы добавить новую
фразу, просто впишите её в соответствующий файл (правило: фраза должна
быть самодостаточной и грамматически завершённой — без дополнительного
склонения при склейке).
