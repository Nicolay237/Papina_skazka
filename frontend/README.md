# Генератор сказок — фронтенд

React-приложение (Vite) — интерфейс для бэкенда на FastAPI. Никакого
выбора слов: одна кнопка — сказка собирается из случайно выбранных слов
(супергерои, интернет-мемы и прочая дичь) и показывается как книжный
разворот.

## Запуск

Сначала запустите бэкенд (см. README в папке `backend/`), затем:

```bash
cd frontend
npm install
npm run dev
```

Приложение откроется на http://localhost:5173 и по умолчанию обращается
к бэкенду на http://localhost:8000. Если бэкенд работает на другом адресе,
скопируйте `.env.example` в `.env.local` и укажите нужный `VITE_API_BASE_URL`.

## Сборка для продакшена

```bash
npm run build   # соберёт статику в dist/
npm run preview # локальный просмотр собранной версии
```

## Структура

```
src/
  api.js               — запрос к /api/generate/random
  App.jsx              — управление экранами (welcome → generating → story/error)
  index.css            — дизайн-токены (цвет, шрифты) и глобальные стили
  components/
    WelcomeScreen.jsx   — стартовый экран с кнопкой «Собери мне сказку»
    LoadingScreen.jsx   — экран ожидания при генерации
    ErrorScreen.jsx     — экран ошибки (например, бэкенд недоступен)
    StoryPage.jsx        — сказка: книжный разворот с буквицей, кнопками
                            «Скопировать», «Скачать .txt» и «Ещё одну!»
    Ornament.jsx          — декоративный svg-орнамент
```

## Дизайн

Тёмный ночной фон, кремовая «бумага» для сказки, золотые и лаковые красные
акценты — контраст между народной эстетикой и содержанием (Бэтмен,
живущий в хрущёвке, и всё в таком духе). Заголовки — Yeseva One, текст —
PT Serif (обе с полной поддержкой кириллицы).
