# Генератор сказок

Полноценное веб-приложение: отвечаешь на 20 вопросов, выбирая слова из
заранее заданных наборов, — и получаешь связную сказку, в которой все
слова правильно склонены и согласованы между собой.

- `backend/` — FastAPI + pymorphy3, банки слов в JSON, вся морфология
- `frontend/` — React (Vite), пошаговый интерфейс и книжная страница
  с итоговой сказкой

## Быстрый запуск

Терминал 1:
```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

Терминал 2:
```bash
cd frontend
npm install
npm run dev
```

Откройте адрес, который выведет Vite (обычно http://localhost:5173).

Подробности — в README внутри каждой папки.
