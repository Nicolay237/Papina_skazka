# Папина сказка

Сказки из случайных фраз и семейная игра «Чепуха».

- **Сказка.** Выбираете темы (Сказочные, Мультики, Космос, Школа, Страшилки…) и что
  войдёт в сказку (герой, спутник, место, время, занятие, препятствие, помощник,
  слова людей, концовка, мораль). Фразы выпадают случайно или выбираются вручную.
  Сказку можно продолжить новой главой и отправить ссылкой.
- **Чепуха.** Игроки по очереди отвечают на свой вопрос, передавая телефон, и не видят
  чужих ответов. В конце все вместе читают, что получилось, и видят, кто что выбрал.
- **Детский режим** включён по умолчанию: фразы для взрослых не выпадают. Переключатель
  в верхней панели, выбор запоминается в браузере.

В копилке больше 2200 фраз, глаголы согласуются с героями по роду и числу.

- `backend/` — FastAPI, банки фраз в `backend/app/data/*.txt`
- `frontend/` — React + Vite

## Запуск для разработки

Терминал 1:
```bash
cd backend
pip install -r requirements-dev.txt
uvicorn app.main:app --reload --port 8000
```

Терминал 2:
```bash
cd frontend
npm install
npm run dev
```

Откройте http://localhost:5173 (запросы `/api` Vite сам проксирует на порт 8000).

## Выкладка в прод (один процесс)

```bash
cd frontend && npm ci && npm run build      # появится frontend/dist
cd ../backend && pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Если `frontend/dist` существует, FastAPI отдаёт и сайт, и API с одного адреса — CORS
не нужен, а ссылки на сказки (`/s/<код>`) получают превью с началом сказки
в мессенджерах. Перед uvicorn стоит поставить nginx или Caddy с HTTPS.

### Если фронтенд и бэкенд — два отдельных сервиса (например, на Render)

- бэкенду задайте `ALLOWED_ORIGINS=https://адрес-фронтенда`;
- фронтенду перед сборкой задайте `VITE_API_BASE_URL=https://адрес-бэкенда` (без `/` в конце);
- в настройках статического сайта добавьте правило Rewrite: `/*` → `/index.html`,
  иначе ссылки `/s/<код>` будут открывать страницу 404;
- превью сказки в мессенджерах в такой схеме будет общим («Папина сказка»): подставлять
  начало конкретной сказки умеет только FastAPI.
